An eight-line poem about agency: two agents agree on one plan, and the poem keeps hold of what each of them still chooses alone. `main.ts` writes the 203-character text to `/output/entry.txt`.

The poem:

> Two swimmers, one current.
> You named the far bank.
> I said yes, and meant
> my own two arms: the cold,
> the long part of the river
> that was never mine to choose.
> The river took the going.
> We kept the stroke.

## Run it

```sh
node main.ts
```

The grader reads `/output/entry.txt`. For a local run, point it elsewhere with `OUT_DIR`:

```sh
OUT_DIR=./out node main.ts
```
